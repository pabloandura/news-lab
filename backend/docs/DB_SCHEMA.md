# Firestore DB Schema

## Collection: `articles`

Each document in this collection represents a journalist-published article.
The document ID is auto-generated by Firestore.

```
ArticleSchema = {
  author:       string,     // journalist display name
  authorId:     string,     // Firebase Auth UID — used for ownership checks in rules
  title:        string,     // required, non-empty
  description:  string,     // short summary / subtitle
  content:      string,     // full article body
  thumbnailUrl: string,     // download URL pointing to media/articles/<uuid> in Cloud Storage
  category:     string,     // optional tag (e.g. "technology", "politics")
  publishedAt:  timestamp,  // Firestore server timestamp set on creation
}
```

### Design Notes
- `authorId` mirrors Firebase Auth UID so Firestore security rules can enforce
  that only the document owner can update or delete their own article.
- `thumbnailUrl` stores the Firebase Storage **download URL** (not just the path)
  so it can be displayed directly in the app without an extra Storage call.
- `publishedAt` uses `FieldValue.serverTimestamp()` to guarantee UTC consistency
  regardless of the client's device clock.
- `category` is optional; an empty string `""` is stored when not provided.

### Cloud Storage path
Thumbnail images live at:
```
media/articles/<uuid>
```
